# Curric.app

ESL teaching job marketplace for non-native English teachers seeking jobs in Asia.

## Tech Stack
- Next.js 14
- Supabase (Auth + Database + Storage)
- Stripe (Payments)
- Tailwind CSS + Shadcn/ui

## Getting Started

1. Clone the repo
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env.local` and add your Supabase keys
4. Run `npm run dev`

## Features
- Teacher profiles with CV upload
- Job listings with search and filter
- School/employer dashboards
- Application tracking
- Stripe payments
